# 💰 Money Tracker

Money Tracker adalah aplikasi sederhana untuk membantu pengguna mencatat dan mengelola transaksi keuangan secara lebih mudah.

## ✨ Fitur

- 💵 Melihat total saldo
- 📥 Mencatat pemasukan
- 📤 Mencatat pengeluaran
- 🏷️ Memilih kategori transaksi
- 📅 Menentukan tanggal dan waktu transaksi
- 🔍 Mencari transaksi
- ✏️ Mengedit transaksi
- 🗑️ Menghapus transaksi
- 📋 Melihat riwayat transaksi

## 📱 Tampilan Aplikasi

Aplikasi memiliki beberapa halaman utama:
- **Dashboard** — menampilkan saldo, total pemasukan, total pengeluaran, dan riwayat transaksi.
- **Tambah Transaksi** — digunakan untuk menambahkan transaksi baru.
- **Edit Transaksi** — digunakan untuk memperbarui data transaksi yang sudah ada.
- **Hapus Transaksi** — digunakan untuk menghapus data transaksi.


## 🎯 Tujuan

Aplikasi ini dibuat untuk membantu pengguna mencatat pemasukan dan pengeluaran serta memantau kondisi keuangan dengan lebih terorganisir.

## 🛠️ Teknologi

- Android
- Kotlin
- XML / Android UI
- Material Design

## 👨‍💻 Pengembang

Dibuat sebagai proyek aplikasi pencatatan keuangan sederhana.
